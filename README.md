## What is Advent of Code?

**Advent of Code** is an annual series of programming puzzles released every **December**.  
It is designed to help developers practice problem-solving, algorithms, and coding skills in a fun, festive format.

---

## Event Format

### Traditional Format (2015–2024)

- Ran from **December 1st to December 25th**
- One puzzle released each day
- Included a **global leaderboard** based on fastest correct solutions

### Updated Format (2025)

- Ran from **December 1st to December 12th**
- The total number of puzzles was reduced to **12**
- The **global leaderboard was removed**, reflecting concerns around AI-assisted solutions and result integrity
- The focus shifted toward learning, exploration, and problem-solving rather than speed

---

## General Information

- Created by **Eric Wastl**
- First launched in **2015**
- **Free** to participate
- Official website: [https://adventofcode.com](https://adventofcode.com)

New puzzles unlock daily at **midnight EST**.

---

## 📅 How the Puzzles Work

- **One puzzle is released per day**
- Each puzzle has **two parts**:
  - **Part 1** introduces the core challenge
  - **Part 2** expands on the problem with additional complexity
- Solving **Part 1** is required to unlock **Part 2**

---

## 🧩 Nature of the Problems

Advent of Code puzzles emphasize key computer science and problem-solving concepts, including:

- Algorithms and data structures
- Logical reasoning
- Parsing and processing input data
- Optimization and performance
- Mathematical thinking

### Difficulty Progression

- Early puzzles are **beginner-friendly**
- Difficulty increases steadily as the event progresses

---

## 📥 What You’re Given

Each puzzle provides:

- A **story-driven problem description**
- A **personalized text input file**
- A clearly defined **expected output**, usually a number or string

---

Advent of Code is a fun and effective way to sharpen coding skills, explore new ideas, and build a consistent programming habit during the holiday season 🎄

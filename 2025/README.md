## 🗓️ Advent of Code 2025

For the 2025 edition, I chose to solve **Advent of Code using JavaScript**.  
Each day includes a short explanation of the problem, my approach, and the reasoning behind my decisions.

---

### What I Learned
- Building daily problem-solving habits with small, incremental challenges.
- Adapting parsing and algorithmic strategies to a wide variety of problem formats.
- Balancing efficiency and clarity in code design, especially when scaling solutions from Part 1 to Part 2.
